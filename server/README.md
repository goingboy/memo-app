# Memo App Server

便签应用后端服务，基于 Spring Boot 3 + Sa-Token + MyBatis Plus + H2 Database。

## 功能

- 用户注册/登录
- 便签 CRUD（Markdown 支持）
- 分组管理
- 回收站
- 管理员后台

## 技术栈

- Spring Boot 3.2.5
- Sa-Token 1.37.0
- MyBatis Plus 3.5.5
- H2 Database
